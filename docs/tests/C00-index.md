# C00 - Test cases

**Purpose:** The test cases of each area, by test layer: unit tests,
fuzz targets, and conformance checks.

S11-verification-and-spikes says what each test layer is and what gates a
release. A page here lists the cases for one area, and the specs it
verifies name it in their `**Tests:**` line. Each page is
`docs/tests/C<NN>-<slug>.md`. Run `mise run doc:index` to list a new
one here.
