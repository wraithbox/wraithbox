# S00 - Specs

**Purpose:** Every spec, in order. A spec decides how one part of
Wraith Box works and why.

For the repository itself:

- S01-spec-based-development: the kinds of design documents, their
  IDs, and the spec template
- S02-toolchain: languages, tools and checks

The product:

- S03-requirements: the problem, and where the requirements are
- S04-architecture: the processes, and what each one does
- S05-cli: the `wb` commands
- S06-vm-lifecycle: images, VMs and the guest agent
- S07-egress-gateway: the network path out of the guest
- S08-workspace-and-git: how code goes in and work comes back
- S09-policy-credentials-audit: policy, credentials, certificates and
  the audit log
- S10-tech-stack: technology choices
- S11-verification-and-spikes: how the requirements are proven
- S12-platforms: host and guest platforms
- S13-guest-confinement: confinement inside the guest

The other indexes: FR00-index, NFR00-index, SEC00-index, T00-index,
X00-index, R00-index and V00-index.
