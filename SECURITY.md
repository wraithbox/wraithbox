# Security Policy

## Project status

Wraith Box is a personal project in its design phase. Nothing works
yet, there are no releases, and there is no support available.

Do not depend on this project, and in particular do not depend on its
security. There is no mechanism yet for security updates.

The security requirements and threat model the design aims for are in
[SEC00-index](docs/requirements/SEC00-index.md). A way to get around one of
its controls (`SEC*`) is a vulnerability, even before the first release.

## Reporting a vulnerability

Do not open a public issue for a vulnerability.

Please use the "Report a vulnerability" button under the Security tab of
the GitHub project, once it is available there.

If you cannot use GitHub's vulnerability reporting workflow, please
contact @lsimons on GitHub and ask for a private channel, without
including details of the vulnerability.
