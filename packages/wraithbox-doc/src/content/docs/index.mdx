## What it does

<CardGrid>
	<Card title="One command" icon="seti:shell">
		`wb claude` takes exactly the arguments `claude` takes. The first run in a
		git repository sets the project up; later runs start in seconds from a warm
		VM.
	</Card>
	<Card title="Separate kernel, no host files" icon="seti:lock">
		Claude Code and its tools run in a guest VM: macOS on Macs first, Linux and
		Windows guests and hosts later. Nothing from your machine is mounted in;
		work comes back as a git branch you review and land.
	</Card>
	<Card title="No secrets in the guest" icon="approve-check">
		Not even the model credential. A host-side proxy strips what the guest sends
		and injects the real credential, so smuggled tokens are useless.
	</Card>
	<Card title="Default-deny network" icon="warning">
		Every packet goes to a host-side userspace network stack. Only allowlisted
		names resolve, and pushes are limited to the repositories of the projects in the VM.
	</Card>
</CardGrid>
